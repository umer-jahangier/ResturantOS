<objective>
Transform the screen every user lands on, without rebuilding it.

Phase 21 already took the role dashboards off hard-coded palette literals and onto the measured
token layer, and shipped the portlet presets as data with the label-not-swatch chart contract
implemented. The composition is right. What it looks like is flat, and flat is the user's actual
complaint.

So this plan is treatment only, and the boundary matters: a design pass that reorders portlets or
changes a preset has become an unreviewed feature change wearing a restyle's clothes. Every
structural fact on this screen stays exactly where phase 21 put it.

Two specific things are easy to get subtly wrong here and both are asserted rather than reviewed.
A chart that draws itself in is a mask over an unchanged drawing, so the path data must be
byte-identical afterwards — otherwise the animation has silently become a rendering change. And the
direct series labels UI-SPEC §3.4 makes mandatory must be on screen at frame zero, because a
label that arrives when the line finishes is a label a reduced-motion user, a backgrounded tab, or
an interrupted navigation never sees, on a palette whose measured separation under dichromacy is
about sixteen.

Purpose: this is the phase's flagship surface and its before-and-after is the evidence the
definition of done asks for.
Output: transformed dashboards, an honest chart reveal, and captured evidence.
</objective>

    - UI-SPEC §3.12 motion table — the instant duration and the rule that value changes, sorts, filters and row updates do not animate

  </read_first>
  <behavior>
    - The chart's path data after this change is byte-identical to the path data before it, for the same input series.
    - The reveal animates a dash offset only; no other attribute or property is animated.
    - Direct series labels are rendered and positioned at first paint, before the reveal begins, and remain correct throughout it.
    - Under a reduced-motion preference the chart renders fully drawn immediately, with no partial state at any point.
    - A number counts up on first appearance.
    - The same number, given a new value from a refetch, a websocket push, a period change or a filter change, updates instantly with no count-up.
    - Under a reduced-motion preference a number never counts up, including on first appearance.
  </behavior>
  <action>
    Animate the chart by masking, not by redrawing. Keep the path construction exactly as it is,
    give the stroke a dash pattern equal to its own length and animate the offset from that length to
    zero over the reveal duration. Nothing else animates. Then assert the path data is unchanged,
    because the difference between a reveal and a rendering change is invisible on screen and obvious
    in a diff.

    Render the direct series labels outside the mask so they are present at frame zero. This is the
    assertion to write first: UI-SPEC §3.4 measured the minimum separation under deuteranopia at
    about seventeen and under protanopia at about sixteen, and concluded that no five-colour
    categorical palette is safe under dichromacy by colour alone. A label that appears when the line
    finishes drawing is a label that is absent for the whole duration of the animation and absent
    permanently if the animation never runs.

    Under a reduced-motion preference the chart renders complete on first paint. Not fast — complete.
    There is no partial frame.

    Then constrain the count-up. It fires on first appearance and never again, which means it is keyed
    to mount rather than to value. A live dashboard receives pushes; a figure that re-animates on
    every push is a figure an operator cannot read, and phase 20 already ruled that a data update does
    not animate. Under a reduced-motion preference the final value renders immediately.

    Write all seven behaviours as tests first. The path-equivalence and the update-does-not-animate
    behaviours are the two that catch a well-intentioned implementation doing the wrong thing.
  </action>

    - The reveal animates a dash offset and nothing else.
    - Series labels are asserted present at frame zero and under reduced motion.
