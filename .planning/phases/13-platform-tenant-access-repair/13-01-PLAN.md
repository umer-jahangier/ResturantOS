<objective>
Close blocker B1's two infrastructure causes (per D-01): authorities are built from the `permissions`
claim only, so a role can never satisfy `hasAuthority`; and the gateway 401s any token without a
`tenant_id` claim, which every platform user is by definition.

This plan does not add the login endpoint — 13-05 does. It makes a platform token mintable and
acceptable, and ships the live-HTTP verification harness every later plan in this phase uses.

Purpose: without this, the platform API stays dead regardless of what login endpoint is added.
Output: role-derived authorities, a tenant-less token signer, an internal minting endpoint, a gateway
exemption scoped strictly to the platform prefix, and `scripts/e2e/_phase13-lib.sh`.
</objective>
