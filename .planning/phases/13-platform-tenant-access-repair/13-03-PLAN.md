<objective>
Close the two regression classes CONTEXT.md flags as having already bitten this repository more than
once, before any of them can mask a Phase 13 failure.

First (D-32): the gateway maps four route prefixes onto feature codes — payroll, analytics, loyalty
and ecommerce — that exist in no tier matrix. `FEATURE_HR` is present and correct today; `FEATURE_PAYROLL`
is not. Payroll currently lives under the HR prefix so no live request 403s yet, but that is an
accident of routing, not a guarantee, and the same defect shape has already shipped twice (the NLQ
phantom flag and the purchasing phantom flag are both documented in the source).

Second (D-33): tenant status enforcement falls back to active when both the cache and the platform
service are silent. Suspension is the primary non-payment lever and it currently fails open.

Purpose: make feature-code drift a build failure rather than a production 403, and make suspension real.
Output: a closure test, a corrected tier matrix, a fail-closed status path, and a live gating script.
</objective>

    fallback that turns silence into an active determination. On a cache miss, call the platform service;
