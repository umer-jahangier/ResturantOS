## Accomplishments
- `resilience4j.circuitbreaker.instances` now declares all ten instances every gateway route needs — `purchasingCircuitBreaker`, `posCircuitBreaker`, `kitchenCircuitBreaker` and `inventoryCircuitBreaker` no longer silently inherit resilience4j's 60s/1s defaults, closing the "gateway 503s persistently until restart" defect reproduced twice in CONTEXT.md.
- Added a scoped `resilience4j.timelimiter.instances` block (5s timeout, `cancelRunningFuture: true`) for those same four instances only — the six pre-existing instances are untouched.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Initial `GatewayResilienceConfigTest` draft crashed on the gateway's shorthand filter syntax**
- **Found during:** Task 1, first test run
- **Issue:** `default-filters` mixes shorthand string entries (e.g. `DedupeResponseHeader=...`) with map-form filters (`name:`/`args:`). The first implementation assumed every filter list entry was a `Map`, so `ClassCastException: String cannot be cast to Map` was thrown walking `default-filters`.
- **Fix:** Changed the filter-walking helper to accept `List<Object>` and skip any entry that is not `instanceof Map` before inspecting its `name` key.
- **Files modified:** `gateway/src/test/java/io/restaurantos/gateway/GatewayResilienceConfigTest.java`
- **Verification:** `mvn -q -Dtest=GatewayResilienceConfigTest test` exits 0; full `mvn -q -pl gateway test` exits 0
- **Committed in:** e939650 (Task 1 commit — fixed before that commit was made, so no separate fix commit exists)

**2. [Rule 1 - Bug] First application.yml edit violated the plan's own "0 deletions" prohibition gate**
- **Found during:** Task 1, running the prohibition-gate grep myself before committing
- **Issue:** Replacing the existing single-line header comment with new wording counts as 1 deletion + N insertions in `git diff --numstat`, which fails the plan's explicit verification (`git diff --numstat ... reports 0 deleted lines`).
- **Fix:** Reverted to the original comment line verbatim and appended the clarifying text as new lines below it instead of rewriting in place.
- **Files modified:** `gateway/src/main/resources/application.yml`
- **Verification:** `git diff --numstat gateway/src/main/resources/application.yml` now reports `44  0` (zero deletions)
- **Committed in:** e939650 (Task 1 commit — fixed before that commit was made)
