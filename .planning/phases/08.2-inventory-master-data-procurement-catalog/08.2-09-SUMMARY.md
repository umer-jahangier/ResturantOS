## Decisions Made

- Reused `StateInvalidException` (shared-lib, already 409/STATE_INVALID) for the measure-type lock rather than adding a new exception + handler pair.
- Added `IngredientCategoryInvalidException` (422) only for the archived-but-owned case; a tenant-foreign or nonexistent `categoryId` stays a plain `ResourceNotFoundException` (404) — the category truly isn't visible to this tenant.
- `itemType`/`measureType` are plain Strings with DB CHECK constraints, matching inventory-service's own convention (not purchasing-service's enum precedent), per the plan's explicit "follow inventory-service's own convention" instruction.
- `resolveCategoryLookups` and `listIngredients`/`getIngredient`'s category name/path resolution share the same whole-tenant `ItemCategoryRepository` fetch rather than either re-implementing category-tree walking or adding a new method to `ItemCategoryService`.

**4. [Rule 1 - Bug] Fixed a Hibernate flush-ordering bug in the wholesale conversion/allergen replace**
- **Found during:** Task 3 — `IngredientMasterDataIT#updateReplacesConversionAndAllergenSetsWholesale` failed with a live 500 (`duplicate key value violates unique constraint "uq_ingredient_conversion"`).
- **Issue:** `deleteByTenantIdAndIngredientId` was a derived (entity-based) delete method annotated `@Modifying` without an explicit `@Query`. Spring Data JPA still executes this as a load-then-`entityManager.remove()` per row, which Hibernate defers to flush time. Hibernate's flush-time action queue always processes INSERTs before DELETEs regardless of call order, so `IngredientService.replaceConversions`'s subsequent `save()` of a same-key replacement row hit the unique constraint before the old row was actually gone.
- **Fix:** Rewrote both `deleteByTenantIdAndIngredientId` methods as explicit `@Query` bulk JPQL DELETEs with `@Modifying(flushAutomatically = true, clearAutomatically = true)` — a genuine immediate `executeUpdate()`, not a deferred per-entity remove.
- **Files modified:** `IngredientUomConversionRepository.java`, `IngredientAllergenRepository.java`
- **Verification:** `IngredientMasterDataIT#updateReplacesConversionAndAllergenSetsWholesale` passes; full `mvn verify` green.
- **Committed in:** `45bfc5d` (Task 3 commit)
