# Phase 08.2 Plan 04: Purchasing Vendor Item Catalog Summary

**Additive Flyway V5 in purchasing-service: a real vendor item catalog (SKU/pack/UOM/MOQ/lead-time) with append-only effective-dated pricing and filter-only category tags, superseding the dead `vendor_catalogues` table without dropping it.**

## Accomplishments
- Authored `V5__vendor_item_catalog.sql`: `vendor_items` (one ingredient per row via a documented cross-service soft reference, no FK; many rows may share an ingredient across different pack sizes), `vendor_item_prices` (append-only, `effective_from`/`effective_to`, `source` CHECK'd to CATALOG/CONTRACT/INVOICE/MANUAL), `vendor_categories` (filter/suggestion tags only, no purchase-gating column), and a nullable `purchase_order_lines.vendor_item_id` FK with `ON DELETE RESTRICT`. All three new tables carry `ENABLE ROW LEVEL SECURITY` + a `tenant_isolation` policy + `purchasing_user` grants, matching purchasing-service's existing V1 convention exactly (not inventory-service's FORCE+NULLIF form).
- Authored `PurchasingSchemaMigrationIT` (purchasing-service's first schema-proof test class) with 5 tests covering the additive guarantee, RLS/policy presence via `pg_catalog`, the nullable-RESTRICT FK shape, and the two load-bearing invariants (insert-only pricing, multi-pack-size cardinality).
- Verified `vendor_catalogues` and all pre-existing purchasing tables/columns are completely untouched.
