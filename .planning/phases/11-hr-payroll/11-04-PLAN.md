- EmployeeEntity: extends TenantAuditableEntity (from shared-lib), maps the `employees` table (11-01). Fields: id, branchId, userId (nullable), employeeNo, fullName, `@Convert(EncryptedStringConverter) @Column(columnDefinition="bytea") cnic`, `@Convert(EncryptedStringConverter) @Column(columnDefinition="bytea") bankAccountNo`, designation, department, employmentType (enum PERMANENT|PART_TIME|DAILY_WAGE|CONTRACT), joinDate, exitDate, basicSalaryPaisa, isActive, `deviceUserRef` (nullable String — the durable biometric-device PIN->employee mapping key, matching employees.device_user_ref in 11-01; consumed by 11-11's punch ingest).
- EmployeeRepository: JpaRepository; finders findByIdAndTenantId, findAllByBranchId, existsByTenantIdAndEmployeeNo, and `findByTenantIdAndDeviceUserRef(UUID tenantId, String deviceUserRef)` (used by 11-11 PunchIngestService to resolve punches — add it here so 11-11 only reads this repository).

Autowire EventPublisher (DomainEventPublisher bean) exactly like finance JournalEntryServiceImpl.publishJournalPosted.
