<objective>
Implement biometric attendance ingest (HR-07/HR-08): the ADMS/iClock adapter (Mode A) and the USB bridge ingest endpoint (Mode B), both behind the device-authenticated path from 11-10. Punches are idempotent, offline-safe, store both timestamps, quarantine unmapped users, persist to attendance_punches, publish ATTENDANCE_PUNCHED, and store NO raw biometrics.

CRITICAL (RESEARCH):

- Idempotency via native INSERT ... ON CONFLICT (device_id, device_user_ref, device_reported_at) DO NOTHING — NOT the idempotency_keys table (Pitfall 3, high volume).
- ATTLOG field count varies by firmware — parse first 4 fields positionally, ignore extras, never throw on "too many fields", only on "too few to identify PIN+time" (Pitfall 6).
- Mode B is out-of-JVM (separate agent) — only WRITE THE CONTRACT DOC, do not build agent code (RESEARCH Pattern 5).
