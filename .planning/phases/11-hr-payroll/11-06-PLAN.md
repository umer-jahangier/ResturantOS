<objective>
Implement the payroll run lifecycle (HR-02/HR-03 producer side): create a run, calculate payslips per employee using the config-driven tax + EOBI (11-05), approve (TOTP-gated) and mark paid, publishing PAYROLL_RUN_APPROVED then PAYROLL_RUN_PAID for finance to auto-post.

Purpose: This is the orchestration that turns employees + tax config into balanced payroll events. It must be idempotent (Idempotency-Key), TOTP-gated on approval (mirror finance period-close), and must NOT write any JE itself.
Output: /api/v1/hr/payroll-runs run/calculate/approve/pay + payslips + events.

GL flow reminder (for the event payloads finance will consume in 11-08):
  approve -> DR 6200 Salary Expense / CR 2300 Wages Payable (post gross)
  pay -> DR 2300 Wages Payable / CR Bank (post net)
So PAYROLL_RUN_APPROVED payload carries totalGrossPaisa; PAYROLL_RUN_PAID carries totalNetPaisa; both carry runId + branchId.
</objective>
