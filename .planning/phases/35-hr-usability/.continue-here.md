## Critical Anti-Patterns

| Anti-pattern | Severity | Detail |
|---|---|---|
| Bare `git commit` | **blocking** | Eight agents share one index. `git commit -m "..."` commits the WHOLE index including other agents' staged files. ALWAYS `git commit -m "..." -- <explicit paths>`. Never `git add -A/./-u`. |
| `mvn test -Dtest=SomethingIT` | **blocking** | surefire excludes `**/*IT.java`. It will report SUCCESS having run nothing, or run the IT under the wrong config and error on container startup. Use `mvn -pl services/hr-service verify -Dit.test=X -Dfailsafe.failIfNoSpecifiedTests=false`. |
| Trusting incremental `test-compile` | **blocking** | It reported CLEAN against stale `target/test-classes` while three test files did not compile against a changed DTO. `rm -rf services/hr-service/target/test-classes` before trusting a green. |
| Verifying a form by reading its config | **blocking** | Asserting `mode === "onTouched"` proves a string was passed to `useForm`. Type into the form and assert the rendered message. |
